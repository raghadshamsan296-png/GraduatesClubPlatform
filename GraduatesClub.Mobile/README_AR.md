# تطبيق نادي الخريجين - Flutter

التطبيق يعرض الشاشة مباشرة حتى لو كان الـAPI متوقفًا. عند تعذر الاتصال تظهر بيانات تجريبية، وعند تشغيل API يعرض البيانات الحقيقية.

## التشغيل لأول مرة

1. ثبّت Flutter وAndroid Studio، ثم نفّذ `flutter doctor` وتأكد أن Android toolchain والجهاز صحيحان.
2. افتح مجلد `GraduatesClub.Mobile` في Visual Studio Code أو Android Studio.
3. شغّل الملف `RUN_FLUTTER.bat`، أو افتح Terminal داخل المجلد ونفّذ:

```bash
flutter create --platforms=android,web .
flutter pub get
flutter run
```

ملفات Android وWeb الأساسية موجودة داخل المشروع. الأمر الأول يكمل ملفات Flutter المولدة تلقائيًا، ومنها Gradle Wrapper، ولا يحذف واجهات التطبيق الموجودة داخل `lib`.

## ربط API

- محاكي Android يستخدم تلقائيًا: `http://10.0.2.2:5158`
- Windows أو Chrome يستخدم تلقائيًا: `http://localhost:5158`
- هاتف حقيقي: شغّل الهاتف والكمبيوتر على Wi-Fi نفسه، اعرف IPv4 للكمبيوتر ثم شغّل:

```bash
flutter run --dart-define=API_BASE_URL=http://192.168.1.5:5158
```

استبدل `192.168.1.5` بعنوان الكمبيوتر. شغّل `GraduatesClub.API` أولًا، واسمح له عبر Windows Firewall عند ظهور الرسالة.

## المتطلبات المنفذة

- صفحة رئيسية وثلاث صفحات: الخريجون، الفعاليات، الوظائف.
- Drawer وBottom Navigation Bar وAppBar.
- Modal Bottom Sheet من زر المعلومات.
- خط DejaVu مضمّن داخل المشروع.
- تصميم عربي RTL موحّد.
- REST API Integration مع حالة تحميل وإعادة محاولة ووضع عرض احتياطي.

## الفلاتر المضافة

- الخريجون: بحث بالاسم أو البريد أو الهاتف، مع التصفية بالقسم وسنة التخرج.
- الفعاليات: بحث بالعنوان أو الوصف أو اسم الخريج، مع التصفية بالسنة.
- الوظائف: بحث بالمسمى أو المتطلبات، مع التصفية بالشركة.

الفلاتر نفسها متاحة في صفحات الخريجين والفعاليات والوظائف داخل مشروع MVC. ويقرأ Flutter وMVC البيانات المرتبطة من قاعدة البيانات المشتركة عبر الـAPI.
